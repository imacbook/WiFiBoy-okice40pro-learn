# step6：移動方塊（動畫）

## 目的
畫一個會移動的方塊，理解「每張畫面更新一次」的動畫原理。

## 程式碼
```verilog
if (hcnt == 799 && vcnt == 524) begin   // 每張畫面結束時
    box_x <= (box_x >= 600) ? 0 : box_x + 2;
    box_y <= (box_y >= 440) ? 0 : box_y + 1;
end
```
- 方塊位置每張畫面（60Hz）更新一次
- `in_box` 判斷目前像素是否在方塊內

## 應該看到
一個白色方塊在畫面上移動。

## 顯示原理
「動畫」= 每個畫面（60Hz）改變一點點，靠視覺暫留形成連續動作。
