# step1：同步訊號（黑畫面）

## 目的
先讓螢幕「有訊號」，確認 HS/VS 時序正確。

## VGA 的 9 個腳位

| PMOD | 訊號 | 作用 |
|------|------|------|
| p1 | R1 | 紅色最高位 |
| p2 | R0 | 紅色最低位 |
| p3 | G1 | 綠色最高位 |
| p4 | G0 | 綠色最低位 |
| p5 | B1 | 藍色最高位 |
| p6 | B0 | 藍色最低位 |
| p7 | VS | 垂直同步（每張畫面一次）|
| p8 | HS | 水平同步（每條掃描線一次）|
| p9 | Snd | 音訊（本專案接地不用）|

## 顯示原理（重點）
- VGA 是「**逐行掃描**」：從左上角開始，一像素一像素往右畫，畫完一行換下一行。
- 每畫完一行，HS 會送一個**低脈衝**告訴螢幕「換行」。
- 每畫完一張畫面，VS 會送一個**低脈衝**告訴螢幕「換頁」。
- 640×480@60：水平 800 像素（640 可見 + 160 消隱）、垂直 525 行（480 可見 + 45 消隱）。

## 程式碼
```verilog
assign hs = ~((hcnt >= 656) && (hcnt < 752));
assign vs = ~((vcnt >= 490) && (vcnt < 492));
```
- HS：hcnt 656~751 時拉低
- VS：vcnt 490~491 時拉低

## 執行
```bash
cd step1
make
make prog
```

## 應該看到
螢幕出現「無訊號」消失、變成全黑（但螢幕有收到訊號）。
