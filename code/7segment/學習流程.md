# 7 段顯示器 學習流程（一步一步慢慢來）

> 目標：從「點亮一段」→「顯示 00~99 自動計數」。
> 每一步都有一個「看得見的結果」，做到就往下走；卡住就停下來，不用趕。
> 每一步的程式都故意寫得很短：先能動，再變漂亮。

> 🛠️ **可執行版本**：每個步驟都已做成可直接跑的資料夾，放在 [`學習步驟/`](學習步驟/)（`step1/` ~ `step9/`），進去 `make` + `make prog` 就能看到結果。
> 流程看這份（觀念），動手做那份（實作）。

---

## 先備知識（約 3 分鐘，不用寫程式）

| 名詞 | 白話解釋 |
|------|----------|
| FPGA | 一片可以「用程式描述電路」的晶片。你寫 Verilog，它就變成對應的電路。 |
| 12MHz 時鐘 | 板子上每秒震盪 1,200 萬次的時鐘（`clk12`，pin 35）。所有「計時」都靠數它。 |
| 腳位（PCF） | Verilog 訊號要對應板子上的實體腳位，寫在 `.pcf` 檔。 |
| 7 段顯示器 | 7 顆 LED 排成「日」字（a~g），加上小數點（dp）。 |

### 本專案的腳位（已實測確認）

```
段： a=42  b=43  c=44  d=47  e=45  f=3  g=48
位： dig1=2（個位，右）  dig2=46（十位，左）
時鐘： clk12=35
```

---

## 第 0 步：看懂「7 段顯示器」的構造

**先別寫程式，先看圖想懂：**

```
   aaa
  f   b
  f   b
   ggg
  e   c
  e   c
   ddd   （+ dp 小數點）
```

- 每一「段」就是一個 LED，A 到 G 共 7 顆。
- 顯示器有兩種接法：
  - **共陰（common cathode）**：共腳接地，段腳給 `1` → 亮。（本專案預設用這個）
  - **共陽（common anode）**：共腳接 VCC，段腳給 `0` → 亮。
- 接錯極性會「全部亮」或「全部不亮」，所以第 8 步會教你怎麼切。

**✅ 這步完成標準**：能講出「a~g 各在哪」，知道共陰/共陽的差別。

---

## 第 1 步：點亮「一段」（史上最短的顯示程式）

**目的**：確認「程式 → 腳位 → LED」這條路是通的。

**做什麼**：只把 A 段設成 1，其他不管。

```verilog
module seg_one(input clk12, output a);
    assign a = 1'b1;      // 把 A 段永遠點亮
endmodule
```

搭配一份 pcf（只留 `seg_a 42` 和 `clk12 35`）。

**✅ 完成標準**：顯示器的 A 段亮起來。
**⚠️ 沒亮的話**：先換成 `assign a = 1'b0;` 試試——如果這樣反而亮，就是**共陽**，記下來，第 8 步會用到。

---

## 第 2 步：輪流點亮 A~G（確認每一段都正常）

**目的**：確認 7 段都接對、都活著。

**做什麼**：加一個「每秒換一段」的計數器。

```verilog
reg [2:0] step = 0;
reg [23:0] cnt = 0;               // 24 bits 才數得到 1,200 萬
always @(posedge clk12) begin
    if (cnt == 24'd11_999_999) begin  // 12MHz 數 1200 萬次 = 1 秒
        cnt  <= 0;
        step <= (step == 7) ? 0 : step + 1;
    end else
        cnt <= cnt + 1;
end
```

然後用 `case (step)` 決定哪一段亮（參考現成的 `diag_seg.v`）。

**✅ 完成標準**：A→B→C→D→E→F→G 每秒輪流亮，順序正確。

---

## 第 2.5 步（選修）：腳位找不到時，就「逐腳掃描」

**目的**：當你不確定「PMOD 的 p1 對應 FPGA 哪個腳」時，用最笨但最有效的方法找。

**做什麼**：一次只拉高一隻腳，每秒換下一隻（`diag9.v` 就是這個）。

**學到**：硬體除錯的基本功——**先假設、再測、再修正**。
（本專案當初就是靠這個，才發現 PMOD 標示是反的。）

**✅ 完成標準**：你能自己找出「哪個 FPGA 腳 = 哪個 PMOD 腳」。

---

## 第 3 步：解碼器（數字 → 段碼）

**目的**：把「數字 0~9」變成「7 段的亮暗」。

**做什麼**：寫一個純組合邏輯的 module（沒有時鐘）。

```verilog
module seven_seg_decoder (
    input  [3:0] digit,
    output reg [6:0] seg      // {a,b,c,d,e,f,g}
);
    always @* begin
        case (digit)
            4'd0: seg = 7'b1111110;
            4'd1: seg = 7'b0110000;
            // ... 2~9 請對照 seven_seg_decoder.v
            default: seg = 7'b0000000;
        endcase
    end
endmodule
```

**關鍵觀念**：`7'b1111110` 是「哪一段亮」的密碼。從左到右是 a,b,c,d,e,f,g。
所以 `0` 的 `1111110` = a~f 全亮、g 暗 = 正確的「0」。

**✅ 完成標準**：餵 `digit=0` 時顯示 0、`digit=1` 時顯示 1……直到 9。

---

## 第 4 步：單元測試（先模擬，再上板）

**目的**：不要每次都在板子上瞎猜，先用模擬確認邏輯。

**做什麼**：寫一個 testbench（參考 `tb_seven_seg_decoder.v`），餵 0~15，比對段碼。

```bash
iverilog -o tb.vvp tb_seven_seg_decoder.v seven_seg_decoder.v
vvp tb.vvp
```

**✅ 完成標準**：畫面印出 `==> ALL PASS ==`。
**學到**：模擬快、可重複、不用碰硬體，是除錯的好幫手。

---

## 第 5 步：0~9 計數（每秒 +1）

**目的**：讓顯示器自己「動起來」。

**做什麼**：把第 2 步的「每秒 tick」拿來當「數字 +1」的觸發，再接上第 3 步的解碼器。

```verilog
if (tick == 24'd11_999_999) begin
    tick <= 0;
    if (units == 4'd9) units <= 0;
    else               units <= units + 1;
end
```

**✅ 完成標準**：顯示器每秒 +1，0→1→…→9→0 循環。

---

## 第 6 步：0~99（兩位數）

**目的**：加入「十位數」，變成兩位數。

**做什麼**：個位從 9 歸 0 時，十位 +1。

```verilog
if (units == 4'd9) begin
    units <= 0;
    tens  <= (tens == 4'd9) ? 4'd0 : tens + 1;
end else
    units <= units + 1;
```

**✅ 完成標準**：顯示 00→01→…→99→00，每秒 +1。

---

## 第 7 步：多工掃描（兩位數共用 7 根段線）

**目的**：搞懂「為什麼兩位數只要 9 根腳，而不是 14 根」。

**觀念**：
- 如果兩位數各用 7 段 → 需要 14 根腳。
- 多工：段線共用，**一次只點亮一位**，快速輪流切換，靠視覺暫留看起來同時亮。

**做什麼**：加一個約 1kHz 的切換（`refresh` 計數器），輪流把 `seg` 接給個位/十位，並同時切換 `dig1/dig2`。

```verilog
if (refresh == 14'd11_999) begin   // 12MHz / 12000 = 1kHz
    refresh <= 0;
    cur_dig <= ~cur_dig;           // 0=個位, 1=十位
end
```

**✅ 完成標準**：兩位數看起來「同時」亮、不閃爍。
**💡 除錯提示**：如果看起來會閃、或兩位數互相干擾，通常是切換太慢（把 `11_999` 調小）。

---

## 第 8 步：共陰 / 共陽（一組參數搞定）

**目的**：讓同一份程式支援兩種極性。

**做什麼**：加一個 `parameter COMMON_ANODE`，用條件運算子切換。

```verilog
wire [6:0] seg = COMMON_ANODE ? ~seg_pattern : seg_pattern;
assign dig1 = COMMON_ANODE ? ~cur_dig : cur_dig;
assign dig2 = COMMON_ANODE ?  cur_dig : ~cur_dig;
```

**✅ 完成標準**：把 `COMMON_ANODE` 改成 0 或 1，兩種都能正常顯示。

---

## 第 9 步：整合（對照現成檔案）

把前面每一步合起來，就是現成的 `seven_seg.v`。

**✅ 完成標準**：`make` → `make prog`，板子上顯示 00~99 每秒 +1。
