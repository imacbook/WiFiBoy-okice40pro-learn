**段線共用 + 位數分時 → 兩位數看起來同時亮**。

## 目的
搞懂「為什麼兩位數只要 9 根腳，而不是 14 根」。

---

## 程式碼說明

### ① 為什麼要「多工」
- 兩位數各用 7 段 → 要 **14 根腳**，但 PMOD 只有 9 根。
- 解法：**段線共用**，一次只點亮一位，快速輪流切換。

### ② 每秒 1000 次的切換
```verilog
reg [13:0] refresh = 0;
reg cur_dig = 0;
always @(posedge clk12) begin
    if (refresh == 14'd11_999) begin
        refresh <= 0;
        cur_dig <= ~cur_dig;      // 0 ↔ 1 交替
    end else
        refresh <= refresh + 1;
end
```
- `12MHz ÷ 12,000 = 1kHz`（每秒切換 1000 次）。
- `~cur_dig`：位元反向（0 變 1、1 變 0）。

### ③ 段全亮 + 位數交替
```verilog
assign {a, b, c, d, e, f, g} = 7'b1111111;  // 全亮 = 8
assign dig1 = cur_dig;    // 共陰：0 = 啟用
assign dig2 = ~cur_dig;
```
- 段的內容固定是 8。
- 但**一次只開一位**（`dig1` 和 `dig2` 永遠一開一關）。
- 因為切換太快（1kHz），眼睛看起來就是「兩位同時亮」。

## 執行
```bash
cd step7

```

## 應該看到
兩位數都顯示 **8**，看起來同時亮（不會一閃一閃）。

## 除錯
- 會閃 → 切換太慢，把 `14'd11_999` 調小（例如 `14'd5_999`）。
