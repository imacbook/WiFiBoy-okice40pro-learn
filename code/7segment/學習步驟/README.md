# 7 段顯示器：一步一步學（可直接跑的資料夾）

> 每個 `stepN/` 都是**獨立可執行**的資料夾：進去 `make` 編譯、`make prog` 燒錄，就能看到結果。
> 建議照順序做，每步都「看到結果」再往下。

## 步驟總覽

| 資料夾 | 主題 | 你會看到 |
|--------|------|----------|
| `step1/` | 點亮 A 段（最短程式） | A 段亮 |
| `step2/` | 輪流點亮 A~G | 每秒輪流亮 |
| `step3/` | 逐腳掃描（找腳位） | p1~p9 輪流輸出 |
| `step4/` | 解碼器 + 顯示固定數字 | 右邊顯示 3 |
| `step5/` | 解碼器單元測試（純模擬） | `ALL PASS` |
| `step6/` | 0~9 計數（單一位數） | 每秒 +1 |
| `step7/` | 多工示範（兩位數都顯示 8） | 兩位都亮 8 |
| `step8/` | 0~99 計數（多工） | 00→99 每秒 +1 |
| `step9/` | 共陰/共陽切換 | 兩種極性都能顯示 |

## 🎬 互動動畫（9 步都有）

用瀏覽器打開（單檔、免安裝），每份都有章節可切換，網址加 `?ch=N` 可直跳：

| 步驟 | 動畫檔 | 示範什麼 |
|------|--------|----------|
| step1 | `step1/訊號流動動畫.html` | Verilog → FPGA 腳位 → PMOD → 7 段顯示器 |
| step2 | `step2/輪流點亮動畫.html` | 時鐘除頻 → step 計數 → case 選段 → 輪流亮 |
| step3 | `step3/逐腳掃描動畫.html` | 9 腳輪流拉高 → 觀察哪段亮 → 腳位表 |
| step4 | `step4/解碼器動畫.html` | 數字 → case 查表 → 7-bit 段碼 → 顯示器 |
| step5 | `step5/單元測試動畫.html` | testbench 餵 input → 比對 → ALL PASS |
| step6 | `step6/計數動畫.html` | 除頻 1Hz → units 計數 → 每秒 +1 |
| step7 | `step7/多工動畫.html` | 段線共用 + 位數分時 → 看起來同時亮 |
| step8 | `step8/count99動畫.html` | 十進位進位 + 兩解碼器 + 多工 → 00~99 |
| step9 | `step9/極性動畫.html` | parameter 切換 → 共陰/共陽都能用 |

先看懂「為什麼會亮」再動手做，會更有感。

## 怎麼跑

```bash
cd step1
make          # 編譯（約 1~2 秒）
make prog     # 燒錄到板子
```

step5 是純模擬（不用板子）：
```bash
cd step5
make sim
```

## 建議節奏（每天 1~2 步）

| 天 | 做什麼 |
|----|--------|
| 第 1 天 | step1 + step2（先看到東西亮） |
| 第 2 天 | step3（學會找腳位，這是硬體除錯基本功） |
| 第 3 天 | step4 + step5（解碼 + 模擬驗證） |
| 第 4 天 | step6 + step7（計數 + 多工觀念） |
| 第 5 天 | step8 + step9（整合 + 極性） |

## 每步卡住時

每個資料夾都有自己的 `README.md`，內含三部分：
1. **目的**：這步在學什麼。
2. **程式碼說明**：逐段解釋每一塊 Verilog 語法（module / assign / always / case / 拼接…）。
3. **應該看到什麼 + 除錯提示**。
