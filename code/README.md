# WiFiBoy OK-iCE40Pro PMOD 擴充套件驅動

OK-iCE40Pro 的 PMOD 是 12 腳：**9 個訊號（p1～p9）＋ 3 個電源（3.3V / GND / 5V）**。

> ⚠️ **重要發現（2026-11-05）**：使用者讀接腳標示的順序是**反的**（第一個標示＝p9、最後一個＝p1）。以下「訊號對應」表已是**校正後**的正確順序（經 7-segment 逐腳掃描實測確認）。

## PMOD 腳位統一對照

| PMOD pin | FPGA 腳位 |
|---------|----------|
| 1  | 42 |
| 2  | 43 |
| 3  | 44 |
| 4  | 45 |
| 5  | 46 |
| 6  | 47 |
| 7  | 48 |
| 8  | 2  |
| 9  | 3  |
| 10 | 3.3V |
| 11 | GND  |
| 12 | 5V   |
