# step5：混色 8 種

## 目的
RGB 三色各有「亮/不亮」，共 2³ = **8 種組合**。

## 程式碼
```verilog
combo <= combo + 1;   // 0~7 循環

assign r = ~combo[2];   // R
assign g = ~combo[1];   // G
assign b = ~combo[0];   // B
```
- `combo` 0~7，二進位剛好對應 R/G/B 三條線
- `~` 是因為共陽（0 = 亮）

## 8 種組合
| combo | R | G | B | 顏色 |
|-------|---|---|---|------|
| 0 | 0 | 0 | 0 | 黑（全滅）|
| 1 | 0 | 0 | 1 | 藍 |
| 2 | 0 | 1 | 0 | 綠 |
| 3 | 0 | 1 | 1 | 青 |
| 4 | 1 | 0 | 0 | 紅 |
| 5 | 1 | 0 | 1 | 紫 |
| 6 | 1 | 1 | 0 | 黃 |
| 7 | 1 | 1 | 1 | 白 |

## 執行
```bash
cd step5
make
make prog
```

## 應該看到
第 0 顆 LED 每秒換一種顏色（8 色循環）。
