# step1：點亮一顆紅燈

## 目的
確認「色線 + 選線」這組矩陣是怎麼運作的。

## 概念
RGB6 是 **3 條色線（R/G/B）＋ 6 條選線（D0~D5）**：
- 色線決定「這顆 LED 要亮什麼顏色」
- 選線決定「哪一顆 LED 被致能」

同一時間可以只開一顆（step1），也可以開 6 顆（step3 之後用掃描）。

## 程式碼
```verilog
assign r  = 1'b0;   // 共陽：0 = 亮
assign g  = 1'b1;   // 1 = 不亮
assign b  = 1'b1;
assign d0 = 1'b1;   // 共陽：1 = 致能
```
- `r=0` → 紅色通道導通
- `d0=1` → 第 0 顆 LED 被選中
- 其他顏色 =1（不亮）、其他選線 =0（不選）

## 執行
```bash
cd step1
make
make prog
```

## 應該看到
第 0 顆 LED 亮紅色，其他 5 顆不亮。

## 沒亮怎麼辦
- 完全沒亮 → 可能是**共陰**版本，把色線與選線全部反相（0↔1）試試。
- 只有某顆亮 → 選線順序可能相反。
